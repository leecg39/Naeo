## 기능 개선

- 관리자 서비스 상태에 사진 파일 삭제 대기·재시도 건수와 복구 안내를 표시한다. 파일명·사용자 정보·물리 경로는 응답에 포함하지 않는다.
- 삭제 IO 실패에도 사용자의 사진 접근은 즉시 종료되며 물리 삭제는 영속 큐에서 재시도한다. 작업자가 꺼지면 정리는 지연되고 기존 작업자 상태 경고로 드러난다.
- 비밀번호 변경 전 외부 앱도 끊긴다는 점을 안내하고, 변경 후 앱 목록을 갱신한다.

## 인프라·의존성

- QA 서버는 127.0.0.1:3100에서 동작. 다른 작업의 3000 포트는 변경하지 않았다. 배포 인프라·팀원 자격증명·버킷·CI 원격 설정은 제공되지 않아 검증하지 않았다.
- Git 추적 환경 파일은 `.env.example`. 추적된 전체 이력에서 공급자 키·GitHub 토큰·개인키 패턴의 일치 0건. 값은 기록하지 않았다. 정규식 검사만으로 모든 비밀값 부재를 보증하지 않는다(`secret-scan.json`).
- 실제 `npm audit --json`: 알려진 취약점 0건, 총 의존성 360개. 실행 결과 `dependency-audit.json`에 보존했다.
- 도구: Node v25.4.0, npm 11.7.0, 프로젝트 ESLint/TypeScript/Next 빌드. 정확한 설치 버전은 lockfile과 함께 관리한다.
