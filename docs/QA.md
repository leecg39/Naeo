페이지 존재와 첫 화면, 가로 넘침, 보이는 이미지 로딩, 대표 조작을 검증했습니다. 모든 스크롤 위치와 모든 상태를 픽셀 단위로 대조한 결과는 아닙니다. 원본의 로그인 상태와 운영 데이터 변경 때문에 헤더 계정명·수치 등은 차이가 있을 수 있습니다.

## 수정한 주요 문제

- 포털의 서버/브라우저 렌더 순서를 맞춰 초기 hydration 오류를 제거했습니다.
- React 스트리밍 HTML의 실제 본문을 로딩 경계 자리에 결합하도록 추출기를 수정했습니다.
- 홈 타이핑·블러 종료 상태, 실제 두 번째 캐러셀 카드, 본문 이미지 로딩 완료 전환을 복구했습니다. 매거진 상세 20개는 실행 후 DOM으로 다시 수집해 우측 목차를 포함했고, 목차 해시 링크를 현재 글 안에서 유지합니다.
- 추천 키워드 필터는 각 항목의 실제 황금/선점 기회 플래그를 사용합니다. 수집 데이터에는 황금 10개, 선점 기회 0개가 있습니다.
- 영상 소개는 원본의 23개 장면과 9분 40초 타이밍, 재생/일시정지, 이전/다음, Home/End, HUD 표시를 구현했습니다.

## 이미지 캡처의 제한

`blog--guide--dashboard-guide-1440.png`의 첫 본문 이미지는 디코딩 완료 전에 촬영돼 빈 박스로 남았습니다. 동일 파일은 390px·768px 캡처에서 정상 표시되며 이미지와 부모의 `loaded` 상태, 원본 파일을 확인했습니다. 데스크톱에서 이미지가 완전히 표시된 시점의 재촬영은 수행하지 않았습니다. 검증용 브라우저 작업 공간을 사용자에게 반환한 뒤 추가 조작을 중단했습니다. 이후 재검증을 위해 `qa-visual.mjs`에 상세 글 첫 이미지의 로딩·표시 완료 대기를 추가했습니다.

## 남은 범위 제한

- 관리자 11개 주소의 내부 화면은 접근할 수 없어 관찰된 리디렉션만 구현했습니다.
- 로그인·AI 분석/생성·결제·문자·문의 전송은 로컬 데모입니다. 실제 서비스에 쓰기 요청을 보내지 않습니다.
- 랭킹은 수집한 200명이며 추가 운영 데이터는 없습니다. `/preview`는 로컬 초안 관리 화면입니다.
- 원본의 대시보드 가이드 이미지 5개가 HTTP 404입니다. [다운로드 기록](research/naeo.kr/assets-download.json)에 남기고 대체 텍스트를 유지합니다.
- 라이트 테마와 관찰하지 못한 모달은 근사 구현이며, 긴 홈 글쓰기 시연 애니메이션 일부는 정적 상태입니다.
