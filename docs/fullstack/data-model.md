# 데이터 모델

모든 ID는 서버 생성 UUID, 시간은 UTC epoch milliseconds, 수정 가능한 자원은 version 정수로 낙관적 잠금을 적용한다. 사용자가 만든 자원은 owner_id FK를 가진다. 아래는 전체 구현 계약이다. 실제 적용된 테이블은 `src/server/migrations.ts`가 증거이며 계획의 표만으로 구현 완료로 세지 않는다.
