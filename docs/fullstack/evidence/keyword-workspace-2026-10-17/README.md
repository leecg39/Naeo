# 회원 키워드 기능 — 2026-10-17

`/dashboard/recommendations`를 실제 회원 데이터와 API로 연결했다. 캡처된 키워드·이벤트 홍보 대신 개인 키워드 작업 화면을 렌더링한다.

## 구현

- 개인 키워드 추가·이름/분류 수정·삭제, 500자 메모, 즐겨찾기와 작성 완료의 독립 저장.
- 본인 블로그에서 수집한 최근 글의 태그·제목으로 글감 후보 제공. 후보 선택 시 개인 키워드로 추가하며 측정된 추천과 구분한다.
- 공개 추천과 개인 키워드 통합 조회. 검색·분류·기간·기회·작성 상태 필터와 정렬을 전체 데이터에 적용한 뒤 25개씩 표시한다. 조회 조건은 URL에 보존한다.
- 키워드별 글쓰기 링크에 선택한 문구 전달. 데스크톱 표와 모바일 카드, 안내·오류·빈 결과 처리.
- 실제 검색광고 검색량과 네이버 블로그 검색 문서수 어댑터 연결. 미설정/실패/미측정 값을 임의 수치로 채우지 않는다. 문서수 미확인 시 포화도·기회 등급 없음.
- 마이그레이션 47: 개인 `member_keywords`, 기존 저장 상태의 독립 `favorite` 필드. 소유자 격리·버전 충돌·정규화 중복 방지·개인정보 내보내기·탈퇴 연쇄 삭제 포함.

- [데스크톱 개요](desktop.png), [저장된 키워드 상세](desktop-details.png)
- [모바일 개요](mobile.png), [모바일 카드](mobile-cards.png), [저장된 모바일 키워드](mobile-saved.png)
- [실제 로컬 화면](local-empty.png), [브라우저 검증 기록](browser.json)
- 재현: `npm run build` 후 `node --import tsx scripts/qa/keyword-workspace.ts`. `--serve` 옵션은 Ego 검증용 서버를 유지하며 종료 시 임시 DB·업로드 폴더를 정리한다.

HTTP와 브라우저 CRUD는 임시 SQLite DB·전용 테스트 계정·RSS fixture를 사용했다. 검색광고와 네이버 검색은 실제 HTTP 어댑터를 loopback 응답 서버에 연결해 검증했다. 스크린샷의 검색량·문서수는 검증용 데이터이며 실제 네이버 측정 결과가 아니다. 외부 공급자 호출, 실제 계정 자격 증명 및 과금은 사용하지 않았다.

현재 개발 환경에는 검색광고·네이버 검색 API 자격 증명이 없다. 개인 키워드 추가·보관·메모·글쓰기 연결은 바로 사용 가능하고, 실측 지표 수집은 해당 연결 설정 후 사용할 수 있다. UI 검증 뒤 분류 입력의 선택 표시를 한 줄로 다듬고 글쓰기 추천 안내를 개인 키워드 포함 내용으로 수정했다.
