화면은 기존 캡처 레이아웃의 헤더·내비게이션을 사용하고, 본문은 React 컴포넌트와 CSS 변수로 구성한다. 원본 계정의 수치·이미지·추천을 앱 데이터로 복사하지 않는다. 원본 캡처에서 남아 있던 헤더 프로필 사진도 현재 회원 이니셜로 교체했다.

## 관찰과 구현의 경계

- 원본의 트렌드 GET 응답에서 `date`, `통합검색 노출`, `AI 추천` 건수 필드를 확인했다. 변화 피드에서 `type`, `occurred_at`, `payload`와 순위 `from/to/delta`를 확인했다.
- 원본 서버의 추천·랭킹 알고리즘은 클라이언트 JavaScript만으로 확인할 수 없다. 로컬의 공개된 기존 진단 및 추천 규칙으로 계산하며, 랭킹 카드에 기준을 표시한다.
- 로컬 인용 공급자는 완성된 검색 결과 화면의 스크린샷을 반환하지 않는다. 갤러리는 실제 저장된 브리핑을 미리보기로 렌더링하고 `저장된 브리핑`으로 구분한다. 미설정·미측정·실패 상태에서 가짜 이미지나 수치를 만들지 않는다.
- 오류·취소·다른 검색어 결과를 인용/노출 감소로 해석하지 않는다. 소유권과 미래 시각을 조회 시점에 확인한다.
- 무료 진단은 연결된 블로그나 AI 인용 측정값을 자동 생성하지 않는다. 다른 블로그 선택도 대표 블로그를 바꾸지 않는다.
- 원본의 최신 이벤트 당첨자 수·체험 만료 알림은 해당 계정의 상태다. 기존 이벤트/구독 데이터와 무관하게 복사하지 않는다.
