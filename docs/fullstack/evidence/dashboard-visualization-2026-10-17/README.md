# 블로그 분석 결과 도식화

2026-10-17 / 화면: `/dashboard`, 무료 진단 리포트 `/mate/s?r=…`

## 구현

- 저장된 종합 점수 게이지, 이전 진단 대비 증감, 5개 기준 레이더·진행 막대·분석 근거.
- 7일·30일·90일·전체 기간 선택, 진단 점수 / AI 인용·검색 노출 지표 전환.
- 측정 시각에 비례한 그래프, 마우스·터치·키보드로 측정값 확인, 원본 수치 표.
- AI 인용률·통합검색 노출률, 인용된 글 카드에서 해당 인용 상세 팝업 연결.
- 실제 회원의 순위를 표시하고 기존 캡처의 샘플 랭킹 그래프와 가짜 기간 전환 동작 제거.
- 무료 진단 팝업에서도 같은 점수 도식을 사용하며, 패널 너비에 따라 배치 변경.

## 데이터 기준

- 로그인 회원이 선택한 블로그의 기록만 사용. 점수·AI 인용 기록은 각각 최근 365회까지 조회.
- 무료 진단 연결과 블로그 선택 검증은 [후속 검증 기록](../dashboard-mate-2026-10-17/README.md) 참조.
- 기간은 한국 시간의 날짜 기준. 기록이 없는 날을 0으로 보간하지 않음.
- 인용률 분모는 확인에 성공한 글 수. 확인 실패한 글은 제외하고 실패 개수를 별도 표시.
- 미측정은 `—`, 실제 0건은 `0%`. 다른 평가 규칙으로 계산한 점수는 증감 비교하지 않음.
- 공급자 미설정·확인 중·최근 실패·기록 없음 상태 안내. 마지막 성공 기록이 있으면 함께 표시.

## 검증

- `npm test`: 500개 통과 (일반 12개 + 서버 488개).
- 관련 회귀 테스트: 16개 통과. 회원·블로그 격리, 실패 결과 제외, KST 경계, 한 점/0점, 시각 간격 포함.
- 마지막 변경 후 대시보드 관련 10개 테스트 재검증 통과.
- `npm run lint`, TypeScript 검사, `npm run build` 통과.
- Ego Lite, 별도 임시 DB와 localhost:3107 테스트 서버 사용. 실제 사용자의 블로그/진단 데이터 수정 없음.
- 7일 선택: 3개 측정점, 90일: 6개, 전체: 7개. 인용 2개 시리즈: 전체 14개 측정점.
- 키보드 선택: AI 인용 3/9개(33%), 검색 노출 8/9개(89%) 확인. 기록 표 7행 확인.
- 데스크톱 1440px, 모바일 390px에서 가로 넘침 없음. 모바일 그래프는 실제 패널 너비로 다시 그려 축 글자 크기 유지.
- 인용 카드 클릭으로 해당 글 상세 팝업 열림. 빈 계정에서 가짜 그래프·점수 없이 연결 안내 표시.
- 무료 진단 팝업에서 5개 기준과 도식 표시 확인.
