# QA 관리자 블로그 연결 및 글쓰기 추천

## 적용 결과

- 현재 로그인 회원의 기존 `QA 관리자 블로그` 대표 주소를 테스트용 `qa-admin-blog`에서 `leecg39`로 변경했다. 프로필 이름·권한은 변경하지 않았다.
- 네이버 공개 RSS에서 [EvoOntology 글](https://blog.naver.com/leecg39/224444669929)을 실제 수집했고, 기존 추천 엔진으로 키워드 15개가 생성됐다. 다른 계정의 데이터나 예시 글을 넣지 않았다.
- `/dashboard/recommendations`에 **글쓰기 추천**을 추가했다. 현재 검색·필터 목록에서 미작성 주제를 최대 3개 골라 제목 후보 3개, 독자, 목차 4개와 작성 지침을 제공한다. 같은 주제의 반복 노출과 `첫글` 같은 기본 태그는 대표 글감에서 제외한다.
- 전체 키워드의 상세 화면에서도 추천 구성을 사용할 수 있다. 제목을 선택하고 **이 구성으로 초안 열기**를 누르면 출처를 포함한 구성 초안을 저장하고 편집기로 이동한다.
- 같은 추천은 기존 초안을 다시 연다. 다른 제목 후보를 선택하더라도 이미 저장한 제목·본문을 덮어쓰지 않는다. 초안을 삭제하면 다시 생성할 수 있다.
- 초안을 여는 즉시 편집 영역으로 이동하고 키보드 포커스도 옮긴다. 저장할 때에는 포커스를 다시 빼앗지 않는다.
- 추천 갱신 시간이 존재할 때 Node의 `PM`과 브라우저의 `오후`가 달라 생기던 hydration 오류를 공통 KST 포맷으로 수정했다.

## API·저장

`POST /api/recommendations/feed/:id/draft`

입력: `{version: 양의 정수, titleIndex?: 0|1|2}`. 제목·본문을 요청으로 받지 않고 본인 추천에서 서버가 구성한다.

응답: `{data:{draft,reused}}`. 신규는 201, 기존 초안 재열기는 200이다. 인증·Origin·소유권·버전 검증을 적용하고 15분당 60회로 제한한다. 숨김·작성 완료 상태는 409, 타인 추천은 404다.

마이그레이션 49에서 `drafts.recommendation_id`와 회원·추천별 유일 인덱스를 추가했다. 추천·블로그가 삭제돼도 편집한 초안은 보존하며 연결만 비운다. 개인 데이터 내보내기에 연결 ID를 포함했다.

## 제공 범위

글쓰기 추천은 수집한 주제를 바탕으로 한 편집 구성 제안이다. 완성된 AI 본문이나 검증하지 않은 경험을 생성하지 않으며 토큰도 차감하지 않는다. AI 본문 생성은 기존 공급자 연결 기능을 사용한다. 검색광고 공급자가 연결되지 않은 현재 환경에서 검색량·문서수는 미측정 표시를 유지한다. 네이버 자동 발행은 수행하지 않는다.
