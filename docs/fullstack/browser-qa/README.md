# Ego 브라우저 검증 증거

대상은 기존 83개 경로와 추가 관리자·소셜 제작 7개, 화면 폭은 1440/820/390px이다. 관리자 로그인 세션에서 각 주소를 직접 열어 DOM 렌더링·가로 넘침·브라우저 오류·로컬 리소스 응답을 수집했다. 동적 경로는 대표 주소를 사용한다. 이 점검 자체가 모든 CRUD를 다시 수행했다는 뜻은 아니며, 단계별 CRUD 증거는 상위 `verification.md`에 있다.

- `batch-0.json`~`batch-8.json`: 경로별 3개 화면 크기의 가장 최근 측정. CSS와 회원 표시를 수정한 관련 배치는 다시 실행했다. `at`은 각 실행 시각(UTC)이다.
- `layout-before.json`: 수정 전 발견한 가로 넘침 8건의 기록.
- `summary.json`: 최종 집계·예상 오류와 예상하지 못한 오류 구분.
- `interaction.json`: 초안 저장·재접속·공유·철회·정리 등 별도 상호작용 검증 결과.
- PNG: 대표 화면의 실제 캡처. 계정 설정처럼 계정 정보가 포함되는 화면은 저장하지 않는다.

고정 견본 내보내기의 캔버스는 1080px 원본을 유지하고, 작은 화면에서는 해당 영역 안에서 가로 스크롤한다. 문서 전체 가로 넘침과 구분한다. 유효하지 않은 공유 토큰으로 여는 `/p/:id/images`의 API 404는 의도한 오류 사례다. 중간 실행의 방문 집계 API 429는 15분당 600회 제한에 따른 응답이었다. 재실행한 최종 배치에는 429가 없다. 최종 결과는 270회·가로 넘침 0·페이지 크래시 0·예상 밖 오류 0이며, 없는 공유 링크의 404는 2건 수집됐다. 태블릿에서는 해당 요청 이벤트가 관찰 구간에 수집되지 않았으므로 3건으로 계산하지 않는다.

재현: QA 서버 실행 및 Ego의 관리자 로그인 작업 공간을 준비한 뒤, 프로젝트 폴더에서 `NAEO_QA_SPACE=공간번호 node scripts/run-browser-qa.mjs 0`부터 `8`까지 실행한다. 기본 공간 번호는 인계 시 사용한 7이다. 원본 사이트와의 전 화면 정밀 시각 비교는 별도 미완료 항목이다.
