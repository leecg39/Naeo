# 공개 화면 시각 비교 (원본 naeo.kr ↔ 복제본)

- 실행: 2026-10-16, Chrome DevTools(실제 브라우저), 폭 1440px·390px, clone은 프로덕션 `next start`(`:3200`, `/tmp/naeo-visual` DB)
- 원본은 진행 중인 라이브 서비스다. 복제본 공개 캡처는 `2026-10-13` 스냅숏이다. 이후 추가·삭제됐다는 버전 근거가 확인된 콘텐츠만 "원본 변동"으로 분류하며 자동 복사하지 않는다.
- **REA 후속 정정:** 홈 이미지·콘텐츠를 일괄적으로 "캡처 후 신규 추가"라고 한 판정은 철회한다. 해당 자원과 제목이 캡처 전 수집 번들에도 존재한다. [MP4·원본 변동 재검증](rea-mp4-drift-2026-10-16.md).
- **후속 구현:** 기존 홈 12개 섹션·14개 이미지를 보존하며 공개 랭킹, 글쓰기 5단계 예시·자동/수동 재생, AI 선택을 복원했다. Ego 1440/390px에서 화면·내부 스크롤·선택·동작 줄이기를 확인했다. 아래 원본/클론 수치는 수정 전 관찰 기록이며 새 픽셀 비교 결과가 아니다. [구현 및 새 증거](mp4-home-implementation-2026-10-16.md).

## 방법

1. SSR HTML을 두 사이트에서 같은 경로로 가져와 DOMParser로 구조 지표(h1, img/section 수, header/footer, footer 링크 수)를 비교.
2. 주요 화면(`/`, `/pricing`, `/event`)을 1440·390px으로 실제 렌더링해 문서 높이·가로 넘침(`scrollWidth>innerWidth`)·렌더링 이미지 수를 측정.
3. 차이는 세 부류로 나눴다: 실제 결함 → 수정 / 원본 변동(캡처 이후 라이브가 바뀐 부분) → 추적 대상 / 의도적 대체(복제본이 캡처 그대로가 아니라 자체 데이터로 그리는 부분).

## 이번 비교에서 고친 실제 결함

1. **`/event` 대표 이미지 미표시** — `events` 테이블에 이미지 열이 없어 카드 템플릿의 포스터 영역을 통째로 지우고 있었다. 스키마 44 `cover_image`(로컬 경로만 허용) 추가, 시드 두 이벤트에 캡처된 포스터(`/assets/fc2151ea8a854a0d.png`, `/assets/2e11be7158d9feb4.png`) 연결, 목록 카드·상세 화면에 표시, 관리자 편집기에 필드 추가.
2. **`/login` 문서 제목** — 복제본이 홈 기본 제목을 그대로 썼다. 원본과 같은 `NAEO: 네이버 AI 검색(AEO) 최적화 진단`으로 맞췄다.
3. **`/login` 화면 구조(픽셀 비교에서 발견)** — 복제본이 자체 마케팅 카드(`WELCOME TO NAEO`)를 렌더링해 원본의 "시작하기" 시트와 레이아웃이 완전히 달랐다(모바일 diff 8.5%). 캡처 `login.json`에 존재하는 원본 구조로 재배치했다: "시작하기" 제목+닫기(홈 이동), 네이버/구글 시작 버튼(캡처된 아이콘 에셋 사용), "다른 네이버 아이디로 로그인" 링크(네이버 미설정 시 미표시), 약관 동의 문구, "이메일 로그인" 구분+placeholder 입력+녹색 제출. 회원가입·비밀번호 찾기 링크는 원본에 없는 복제본 기능이라 하단 보조 링크로 유지한다.

한계: 라이브 원본의 동적 콘텐츠·애니메이션 프레임 차이가 비율에 섞인다. 지표는 화면 단위 diff이며 특정 요소의 픽셀 일치를 뜻하지 않는다. 데스크톱은 원본이 스크롤바를 항상 표시해 폭이 1425px로 캡처되고 복제본은 1440px이라 공통 1425px만 비교한다.

## 별도로 추적하는 차이(자동 복사하지 않음)

- 홈 이미지·콘텐츠(`landing/profiles`, `landing/thennow`, `mcp/post`, `mcp/thumbs`, `mate/examples/biz.jpg` 등): 기존 수집 번들에 존재함을 REA 후속 조사에서 확인했다. "10-13 캡처 이후 추가"라는 기존 설명은 정정한다. 당시 노출 조건과 캡처 누락 여부는 미확인이다.
- `/blog` 신규 글과 `blog-default-thumb.webp` 대체 썸네일.
- 홈 문서 제목(`NAEO | ` 접두어를 원본이 제거함).
- 공지 티커: 캡처 본문에는 `visibility:hidden` 상태로 들어 있고, 복제본은 이 영역 대신 자체 공지 시스템(`AnnouncementQueue`, 관리자 등록)을 쓴다. 의도적 대체.
- `/mate`의 인원·금액 수치: 원본은 SSR 플레이스홀더 후 hydration으로 채우고, 복제본은 캡처 시점 값을 표시한다. 운영 데이터라 추적하지 않는다.

## 한계

- 픽셀 비교는 위 표로 수행했다. 측정은 DOM 구조 지표·실측 치수·픽셀 diff까지이며 원본의 세부 애니메이션 프레임 전체 재현은 하지 않았다.
- 로그인 이후 화면, 결제 플로우, 확장 프로그램 화면은 이 비교 범위 밖이다.
- 원본은 계속 바뀌므로 이 표는 2026-10-16 시점 기준이다.
