# 목록 페이지 이동 포커스 보완

2026-10-16

## 코드 점검과 변경

`ListPagination`을 사용하는 관리자 문서·FAQ·공지·이벤트·참여 심사·리워드·쿠폰·결제·환불, 회원 결제·환불 및 사진함에 공통 적용한다.

기존 버튼은 요청 중 또는 첫/마지막 페이지에서 비활성화되며 별도의 포커스 처리가 없었다. 페이지 이동을 누르면 비활성화되지 않는 현재 페이지 표시로 포커스를 옮긴 뒤 조회를 시작하도록 변경했다. 화면 스크롤은 유지한다. 응답 이후 포커스를 강제로 옮기지 않으므로 요청 중 사용자가 다른 곳으로 이동해도 포커스를 빼앗지 않는다.

페이지 표시에 목록 이름, 현재/전체 페이지, 불러오는 중 상태를 읽을 수 있는 status 영역을 추가했다. tabIndex=-1로 일반 탭 순서에는 추가하지 않는다. 화면의 기존 숫자 표시는 유지한다.

## 확인한 범위

- `npm run typecheck`: 통과
- `npm run lint`: 통과
- `git diff --check`: 통과

이 기록은 코드·정적 검사 결과다. 브라우저에서 포커스 손실을 재현하거나 개선 결과를 직접 검증했다는 의미는 아니다. Ego 조회 결과 기존 공간15는 ownership=user였으며, 제어권 규칙에 따라 브라우저 조작을 진행하지 않았다.

## 이어서 필요한 실제 검증

1. 101건 이상인 각 목록에서 키보드로 다음/이전 실행 후 현재 페이지 표시의 포커스 확인.
2. 마지막 페이지에서 다음 버튼이 비활성화되어도 Tab/Shift+Tab으로 사용 가능한 컨트롤 접근 확인.
3. 요청 중 다른 입력으로 이동하면 응답 후 해당 포커스가 유지되는지 확인.
4. 조회 실패·재시도 후 포커스와 오류 안내 확인.
5. 검색 제출/미제출 조건, 마지막 항목 삭제 후 페이지 복귀, 390px 모바일 조작 확인.

P11.3 및 전체 목표는 미완료로 유지한다.
