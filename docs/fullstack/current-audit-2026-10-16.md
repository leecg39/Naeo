Ego에서 자동 재생·단계 선택·내부 스크롤·모바일·동작 줄이기를 확인했다. 10-17 애니메이션 대조로 스크롤 reveal·칭호 광택·명예의 전당 셈을 복원해 실행 중 애니메이션으로 확인했다. 프레임 단위 전체 일치는 미검증이다. [비교 기록](visual-parity-2026-10-16.md), [후속 구현](mp4-home-implementation-2026-10-16.md), [배포·외부 준비물](deployment-prerequisites.md).
- MP4는 `unsupported`에서 FFmpeg 기반 무음 슬라이드 영상 지원으로 전환했다. 실제 Ego 생성·대기 상태 유지·다운로드·취소와 H.264 1920×1080/30fps/2초 파일을 확인했다. 운영 환경은 FFmpeg/libx264와 같은 DB·업로드 폴더를 쓰는 worker가 필요하다. 배포는 수행하지 않았다.
- 공용 페이지 이동의 포커스 처리, 목록 복귀 도중 동시 삭제 처리, 확장 Origin·토큰 clientId 대조, 사진함 마크다운 링크·폐기·재발행, 30일 초안 자동 삭제가 구현됐다.
- 고정 개발 ID를 가진 Manifest V3 확장 본체를 추가했다. 실제 Next HTTP에서 PKCE 동의→토큰→MCP 초안 조회→철회 후 401을 확인했다. [확장 발행 기록](extension-publish-extension.md).
- 실제 Ego Lite와 로그인된 네이버 SmartEditor ONE에서 제목·구조화 본문·소제목·PNG 사진의 4단계 전달, 진행 상태, 연결 해제, 테스트 글 정리를 확인했다. 공개 발행은 누르지 않았다.
- 외부 연동 설정은 로컬 개발 환경의 존재 여부를 새로 검사했다. [설정 확인 결과](evidence/provider-readiness-2026-10-16.json). 값은 기록하지 않았으며 계정 보유 여부나 배포 환경 상태를 뜻하지 않는다.
