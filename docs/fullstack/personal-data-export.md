# 개인 데이터 내보내기 — 2026-10-15

스키마 29에서 **내보내기 요청 → 작업자 생성 → 다운로드 → 취소·삭제·만료 정리**를 구현했다. `/dashboard/settings`에 본인 확인, 상태, 다운로드, 취소·삭제 화면을 연결했다. 원본 NAEO의 개인 데이터 내보내기 기능을 REA로 확인한 것은 아니다. 기존 P9.2 개인정보 이동성 요구에 대한 클론의 별도 설계다. 원본에서 확인한 계약은 [REA 보고서](rea-deep-dive.md)와 구분한다.

## 사용과 API

| 동작 | 경로 | 조건·결과 |
|---|---|---|
| 요청 | `POST /api/auth/data-exports` | 비밀번호 계정은 `{currentPassword}` 재인증. 비밀번호 없는 소셜 계정은 `{}`와 로그인 10분 이내 세션. 성공 202 |
| 상태 목록 | `GET /api/auth/data-exports` | 현재 계정·현재 로그인에서 요청한 유효 작업 |
| 다운로드 | `GET /api/auth/data-exports/:id/download` | 본인 세션·활성 계정·완료·만료 전, `application/x-tar`, attachment, no-store |
| 취소·삭제 | `DELETE /api/auth/data-exports/:id` | 처리 중 취소와 완료 파일 삭제. 내보낸 원본 데이터는 유지 |

요청은 계정당 시간당 5회로 제한한다(실패 요청도 포함). 동시에 준비 중인 작업은 계정당 1개다. 요청 후 1시간 또는 현재 세션 만료 중 빠른 시각까지 유효하다. 다른 기기의 로그인에서는 같은 계정이어도 해당 요청을 조회·다운로드하지 못한다. 비밀번호 재검사 후 세션·비밀번호·계정 활성 여부를 다시 확인해 검증 도중 로그아웃한 요청을 거절한다.

`npm run worker`가 준비 작업과 정리를 수행한다. 작업자가 꺼져 있으면 대기 상태이며 생성 완료로 표시하지 않는다. 10분 lease, 최대 3회 중단 복구를 사용하고, 각 실행의 무작위 키로 이전 작업자의 늦은 결과가 현재 결과를 덮어쓰지 못하게 한다.

## 포함 범위

TAR에는 `data/*.ndjson` **41개 데이터셋**, `attachments/` 아래 실제 파일, `manifest.json`이 있다. 각 NDJSON 줄은 레코드 1개이며 빈 데이터셋은 0바이트 파일이다. `_json` 열은 기존 JSON 문자열을 보존한다. 명시적인 열 목록과 본인 소유권 조건으로 조회하고 UI의 10/50/100개 페이지 제한을 적용하지 않는다.

| 범위 | 포함 데이터 |
|---|---|
| 계정 | 계정·프로필·연락처·알림 설정·동의 이력·로그인 시각·감사 이벤트의 안전한 필드 |
| 블로그·분석 | 등록 블로그·수집 글·진단 작업과 수집 결과·진단 보고서·메이트 보고서·경쟁 블로그·할 일·저장 키워드 |
| 글·사진 | 초안·전체 수정 이력·사진 메타데이터·공유 생성/만료/철회 시각·토큰 원장·생성 작업 입력과 결과 상태 |
| 제작 | 프로젝트·슬라이드·내보내기 이력·유효한 완료 PDF/ZIP·수집 중 PNG |
| 활동 | 본인 랭킹 기록·이벤트 참여/심사 안내·보상·포인트·출석·튜토리얼·서브 주제·랭킹 방문 |
| 결제 | 구독·결제·환불·쿠폰 사용 및 관련 표시 정보 |
| 연결·문의 | 소셜 연결·외부 앱 권한의 안전한 정보·MCP 호출 이력·본인 문의·모든 전달 상태의 답변 |

사진은 `draft_id IS NULL`인 것도 `owner_id`가 본인이면 포함한다. 원본 이름은 manifest의 메타데이터로만 보존하며 TAR 경로에는 서비스 ID를 쓴다. 완성 파일과 수집 중 페이지의 경로·크기·SHA-256도 manifest에 기록한다. 이미 만료된 제작 산출물은 이력만 포함하고, 현재 존재해야 하는 파일이 누락되거나 읽는 중 변경되면 **전체 작업을 실패** 처리한다.

회원 API에 원래 공개되는 `review_note`, `decision_note`, `credit_ledger.note`는 포함한다. 문의 답변의 `not_configured/failed/sent`도 모두 포함하되 답변자 식별자는 제외한다. 이메일만 일치하는 비회원 문의는 소유권 근거가 없어 포함하지 않는다.

## 제외·일관성·보관

- 비밀번호/해시, 세션·OAuth 토큰/해시·인가 코드·state·verifier·토큰 family, 결제 승인 키, 실제 공유 capability, 멱등/lease 키, 내부 저장 키를 제외한다.
- 다른 회원·관리자 식별자, 감사 payload와 대상 ID, 공용 CMS·운영 설정·익명 집계는 제외한다. 새 DB 열이 생겨도 자동으로 포함하지 않는다.
- 외부 URL은 문자열로 보존하며 외부 콘텐츠를 다운로드하지 않는다. 삭제된 데이터나 별도 백업에서 복원하지 않는다.
- DB는 작업 시작 시 읽기 트랜잭션의 snapshot을 사용한다. 첨부는 크기·수정 시각을 확인하며 128KiB씩 읽는다. DB와 파일시스템을 하나의 원자 snapshot이라고 주장하지 않는다. 파일이 동시에 삭제·변경되면 재요청이 필요할 수 있다.
- 전체 파일을 메모리에 올리지 않는 USTAR 방식이다. 전체 아카이브의 ZIP32 4GiB 제한은 없으며 단일 TAR member는 약 8GiB 한계에서 명시적으로 실패한다. 실제 5GB 전체 계정 부하 테스트는 수행하지 않았다.
- 보관 파일은 웹 루트 밖 `NAEO_UPLOAD_DIR/personal-exports`, 파일 0600·생성 폴더 0700이다. 파일 키·심볼릭 링크·정규 파일 여부를 확인한다.
- 로그아웃·세션 철회·비밀번호 변경·탈퇴는 FK cascade로 접근을 끝내고 영속 삭제 큐를 만든다. 정리 작업은 통상 1분 주기이며 중단·IO 실패 시 재시작 후 재시도한다. worker가 중단된 동안 물리 삭제는 지연된다.
- 삭제 실패는 재시도 시각·오류 코드로 기록하고 다른 삭제를 막지 않게 순환한다. DB에 연결되지 않은 중단 파일은 1시간 이후 회수한다. 이미 내려받은 사본과 운영 백업은 별도의 보관 대상이다.

## 실제 검증

전용 **18개 테스트**, 전체 **357개(6+351)**, lint·typecheck·프로덕션 build가 통과했다. [검증 색인](evidence/personal-export-verification.json)에는 소스·증거 해시와 실행 결과가 있다.

초기 미구현 실패를 확인한 뒤 구현했다. 추가 검토에서 `readdirSync` 접근 오류가 worker 전체를 종료하는 문제와, 실패한 삭제 100건이 뒤의 정상 파일을 계속 막는 문제를 각각 재현했다. 수정 전 회귀 결과는 **16 통과 / 2 실패**, 수정 후 **18 통과**다. 수집 결과 `scan_jobs.result_json` 누락도 보완했다.

테스트에는 타 계정·다른 로그인 접근, 재인증 도중 세션 폐기, 계정 삭제, 실제 두 DB 연결 간 logout/lease 경합, 파일 누락·symlink·경로 조작, 1,200개 원장 행, 문의 전달 상태, 제작 중/완료/만료 파일, 삭제 재시도를 포함한다.

[프로덕션 HTTP 근거](evidence/personal-export-runtime.json)는 격리된 DB·임시 포트·실제 Next 서버와 worker로 확인했다. 재현 명령:

```sh
npm run build
node --import tsx scripts/qa/personal-export.ts
```

실제 HTTP로 계정 2개·글·사진을 만들고 비밀번호 오류 403, 요청 202, 준비 전 다운로드 409, 다른 소유자 404를 확인했다. worker가 생성한 TAR를 다운로드한 뒤 `/usr/bin/tar`로 모든 member를 읽어 **41개 데이터셋과 사진 1개**, 크기와 SHA-256, 본인 데이터 격리와 원본 사진 바이트를 대조했다. 로그아웃 직후 401 및 worker 재시작 후 파일 삭제도 확인했다. QA 자격 증명은 메모리에서 생성했고 임시 서버·worker·DB·파일은 정리했다.

설정 페이지 SSR에 UI가 렌더링되는 것은 확인했다. **Ego에서 클릭·hydration·반응형 화면을 검증하지는 않았다.** 기존 NAEO 작업 공간 부재와 새 공간 승인 대기는 그대로다. P9.2의 브라우저 검증과 전체 외부 연동·원본 시각 비교 항목을 완료 처리하지 않는다.
