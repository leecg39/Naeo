# TASKS 후속 구현·검증 및 외부 완료 조건 — 2026-10-16

사용자의 `TASKS.md 이어서 끝까지 구현` 요청으로 미완료 14개 항목을 코드·실행 증거와 대조했다. 로컬에서 수행 가능한 계정 브라우저 검증과 발견 결함 수정, 전체 회귀 검사, 문서 정리를 완료했다. 외부 공급자의 실제 왕복은 설정이 없어 완료할 수 없으며, 해당 체크를 완료로 바꾸지 않았다.

## 이번에 완료한 작업

1. 이메일 인증·비밀번호 재설정 완료 화면에서 제거된 제출 버튼의 포커스가 `BODY`로 빠지는 문제를 재현했다. 기존 `OperationNotice`를 적용해 성공 안내에 포커스를 복원했다.
2. 휴대폰 인증 성공 시 연락처 버전 갱신으로 입력 컴포넌트가 다시 생성되면서 성공 안내와 포커스가 사라지는 문제를 재현했다. 유지되는 부모 연락처 컴포넌트에서 결과를 안내하도록 수정했다.
3. `scripts/qa/account-browser.ts`를 추가했다. 임시 DB·무작위 QA 비밀번호·암호화 키·로컬 Resend/Twilio 수신기·프로덕션 웹/worker를 함께 실행한다. 다른 서버와 쿠키가 섞이지 않도록 IPv6 루프백을 사용하고, 종료 시 작업자·서버·비밀값·DB를 정리한다. 실제 메일·SMS는 발송하지 않는다.
4. MP4·홈 복원과 이번 수정을 포함해 **490개 테스트(루트 12 + 서버 478)**, lint, typecheck, 프로덕션 빌드를 통과했다. 이번 포커스 수정은 실제 브라우저 재현·수정 전후 관찰로 검증했다.
5. README·CHANGELOG·TASKS·운영/감사/검증 기록을 갱신했다. 이전 README의 MP4 미지원, 변경 기록의 홈 차이 일괄 upstream drift 판정을 정정했다.

## 실제 Ego Lite 결과

격리한 최신 프로덕션 빌드, TaskSpace 7, 데스크톱 및 390×844 화면을 사용했다. 각 성공 화면 스크린샷을 직접 열어 확인했다. 임시 QA 계정은 UI로 탈퇴했고 작업 공간과 웹/worker를 종료했다.

| 흐름 | 관찰 결과 |

| 이메일 인증 | 메일 요청→실제 작업자/로컬 수신→링크 열기만으로는 미인증→명시적 확인→성공 포커스. URL fragment 제거, 사용한 링크 재사용 거절 |

## 아직 닫을 수 없는 항목

확인 시 저장소에는 `.env.example`만 있었고 현재 실행 환경에도 `NAEO_*`/`ANTHROPIC_API_KEY`/`OPENAI_API_KEY` 설정이 없었다. 설정된 별도 환경·배포 주소의 위치를 사용자에게 요청했으며 아직 제공되지 않았다. 다른 프로젝트의 비밀값을 검색하거나 임의 공급자 계정을 만들지 않았다.

## 계정 브라우저 검증 재현

```bash
npm run build
node --import tsx scripts/qa/account-browser.ts 3299
```

출력의 `statePath`에는 이 실행에서만 사용할 QA 로그인 정보와 로컬 수신 내용이 있다. 해당 파일을 저장소에 넣지 않는다. 웹 주소는 `http://[::1]:3299`이며 Ego Lite의 같은 작업 공간에서 로그인해 위 흐름을 따른다. 종료는 실행 터미널에서 Ctrl+C다. 다른 서버가 사용 중인 포트는 시작 전에 거절한다.
