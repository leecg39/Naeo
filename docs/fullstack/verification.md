### 구현 상태와 아직 남은 범위

DB·마이그레이션·자체 가입/로그인·세션·로그아웃·프로필 조회/수정·블로그 CRUD·설정 UI를 구현했다. 관리자 승격 CLI는 있지만 사용자 관리 UI/CRUD는 아직 없다. 프로필 생성은 가입과 함께 이루어지며 탈퇴/삭제는 P1.6에서 이어서 구현한다.

비밀번호 변경/재설정, 메일·휴대폰 검증, 계정 탈퇴, 관리자 CRUD, 연락처·설정 확장은 남아 있다. P2–P8 콘텐츠·문의·수집/분석·추천·경쟁자·글쓰기·이미지·랭킹·이벤트·보상·결제·OAuth·MCP·소셜 내보내기도 미완료다. 과거 clone QA의 79 URL 성공은 이 기능들의 구현 완료를 뜻하지 않는다. `page-coverage.json`은 전체 요구가 끝나지 않은 경로를 pending 상태로 유지한다.

AI/OAuth/결제/SMS/메일 개발 설정은 미확인이다. 원본 로그인 세션이나 GitHub 로그인은 공급자 앱 설정을 대체하지 않는다. DB·CRUD 구현은 계속 진행할 수 있다.

## 2026-10-13 — P2.1 매거진 기사 DB 이관 (기사·카테고리)

설계: 기사 본문은 GFM 마크다운으로 저장한다. 원본 MDX의 특수 구성 요소는 지시문 3종(`event-cta`(+`button="true"`), `picture`, `mate-promo`)만 허용한다. 원본 HTML은 실행하지 않고 글자로 표시한다. 링크는 `http(s)`·`mailto`·`#`·`/` 경로만, 이미지는 `https`·`/` 경로만 허용한다. 서버에서 마크다운을 캡처 노드 트리로 변환하고 기존 `NodeRenderer`가 그린다. 원본 클래스를 그대로 써서 스타일을 유지한다. 화면 틀은 캡처한 `/blog/marketing/golden-keywords`·`/blog`를 쓰고, 사이드바·경로 표시·머리말·본문·태그·이전/다음·목차·목록 카드·분류 탭은 DB 값으로 다시 만든다. 원본 결함과 의도적 차이:
- 원본 버그 보정: 경로 표시의 현재 글 제목 span이 inline이라 원본의 `max-width`·말줄임이 적용되지 않는다. naeo.kr 실측 결과 이벤트 글이 390px 화면에서 440px로 넘친다. `display:inline-block` 보정 규칙 하나를 추가해 180/320px 말줄임을 적용했다.
- 원본에도 없는 이미지: `dashboard-guide`의 6-1~7-2 이미지 5개는 naeo.kr에서도 HTTP 404다(캡처 다운로드 기록). 클론도 같은 상태이며, 이미지 크기를 알 수 없어 width/height 없이 렌더링한다.
- 분류 탭에 `data-category`를 추가했다. 관리자가 만든 새 분류도 필터되도록 behavior가 이 값을 우선 사용한다.
